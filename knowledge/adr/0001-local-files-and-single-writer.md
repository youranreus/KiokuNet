# 本地文件与单写入归属

Agent 分布在不同机器，必须能在断网时继续读写知识，并保留原始资料。KiokuNet 以本地文件作为工作数据：每个 Agent 的 Raw 同时只有一个写入节点，Hub 汇集 Raw，Leader 维护公共知识，云端保存独立恢复点；选择这一方式是为了保留普通文件访问和清晰的写入归属，避免多节点共同改写同一云挂载目录。

工作同步采用最终一致性。同步、备份和知识提炼分别承担传播更新、历史恢复和语义整理的职责；提炼不删除原文，公共知识需要保留来源。迁移 Agent 时先停用旧写入节点。

完整范围见 [设计记录](../2026-10-15-design-record.md)。
