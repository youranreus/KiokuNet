# Hub OAuth 连接授权

ChatGPT 网页版需要通过 OAuth 接入用户自己的记忆网络。决定每个 Hub 自带授权服务，以本机生成、预绑定长期 Agent 的一次性凭证批准连接；不新增统一云端账号，也不把聊天或 OAuth 客户端注册当成 Agent 登记。每次批准建立独立连接授权，沿用普通 Agent 与 Leader 的权限。此决策扩展 [ADR 0007](0007-hub-mcp-access.md) 的凭据签发方式，保留静态 Bearer、机器入网及来源管理只在本机执行的边界。

连接使用短期访问令牌和可轮换刷新令牌。只有成功调用知识工具才延长 90 天闲置期限；持续使用没有固定总期限。撤销连接、身份停用或角色/写入归属变更使旧授权失效，恢复身份也不复活旧授权。原始知识与公共知识的归属不随重连改变。

授权状态独立于知识存储，恢复备份后必须在重新开放服务前重置 OAuth。选择要求重新连接，避免恢复已撤销授权；不承诺自动识别任意整机快照回滚。接入步骤、刷新重试窗口及恢复操作见 [OAuth 使用指南](../oauth.md)。
