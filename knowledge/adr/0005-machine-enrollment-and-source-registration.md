# 机器入网与来源登记分离

> 2026-10-17：[ADR 0007](0007-hub-mcp-access.md) 允许 Leader 通过 MCP 远程执行，shared 的持有与写入仍在 Hub。其余机器配对、来源登记和单写入约束保留。

用户需要先部署机器，再独立接入长期助手，而现有邀请把设备配对与 Agent 来源绑定在一起。决定将机器入网、来源登记和工作区接入分离：Hub 和节点可以没有 Agent；已入网机器新增来源无需重复邀请或 Hub 逐项批准，后台自动登记与同步，离线创建的 Raw 在联网后接续处理。信任单位由单个受邀来源转为已配对节点，但仍保留来源的单一写入节点约束，新增来源不能接管其他节点的归属。

Hub 汇集全部 Raw，其他节点只同步本机 Raw 和 shared。首版 Leader 位于 Hub，直接维护 shared，避免为远端 Leader 增加全部 Raw 分发和公共知识写入归属协议。同一来源可链接同机多个工作区，工作区不自动创建身份。KiokuNet 继续只管理基础设施，不成为 Agent 执行器。

本决策调整 ADR 0004 保留的配对与来源登记关系，保留其普通文件接入和单写入约束。统一安装根目录及操作行为见 [设计记录](../2026-10-16-machine-and-agent-access-design.md)；本决策已实现，验证范围见 [实现记录](../implementation.md)。
