# 工作区目录接入与当前状态

> 2026-10-16：配对与来源登记关系由 [ADR 0005](0005-machine-enrollment-and-source-registration.md) 调整；强制系统账号与权限隔离由 [ADR 0006](0006-readonly-shared-workspace-copies.md) 的只读副本防误写方案取代。后两项已实现；下文保留原决策，文件读写、链接冲突保护及取消历史保留等未被替代部分仍有效。

Agent 通过工作区中的普通文件目录使用记忆。共享目录和自己的 Raw 入口分别可配置，以源目录表示归属；Agent 不再安装 memory Skill、传入身份或调用 context。配对与单写入节点检查继续使用内部目录标识，旧配置和管理命令中的 agent ID 作为兼容名称保留。工作区入口不自动触发 Agent 阅读，也不改写运行器提示词。

符号链接提供路径映射，系统权限提供访问隔离。普通 Agent 共享只读、自己的 Raw 可读写；Leader 可写公共知识、只读其他 Raw。首个后端采用独立的无特权系统账号，检查源路径、父目录、私有配置及实际 POSIX 权限；不支持的 ACL、同账号基础设施或其他无法验证的环境拒绝接入。系统账号由管理员准备，Agent 进程必须实际使用该账号且没有 sudo、服务管理或凭据访问权限。CLI 不成为 Agent 执行器。Raw 与 Hub shared 的顶层目录向专用基础设施组开放写权限，允许同步控制文件安全地原子替换；Agent 不加入该组。可信的基础设施和 Leader 负责维持共享文件权限；权限检查不会限制管理员本身。

Raw 可自由编辑、重命名和删除，自由组织内容。Leader 的 curate Skill 处理当前文本和来源变化，不要求追加记录模板。公共知识可保留已失效来源，不承诺找回引用时的原文；删除来源不自动删除公共结论。取消历史保存、备份快照及恢复功能，现有备份数据、凭据和历史目录不自动删除。迁移仅转移当前文件，不提供历史恢复。

入口已有不同内容时拒绝覆盖；相同映射可重复执行。解除接入仅删除登记且仍匹配的链接，保留源数据。停用本地来源先解除其登记入口；停止原写入进程仍是迁移前提，解除链接不是撤销系统账号访问权。

本决策取代 ADR 0001 中的原文不变及独立恢复点要求、ADR 0002 中普通 Agent 的 Skill 接入方式、ADR 0003 中运行时身份绑定与同账号可信协作假设。保留本地文件、离线工作、最终一致、单写入节点和基础设施与 Agent 执行分离。
