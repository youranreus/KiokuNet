# 机器、知识空间与显式访问授权

用户希望产品只管理机器与知识目录，不替使用方定义助手身份、执行角色或知识处理流程。决定以 Node 与 Knowledge Space 为核心概念，暂保留独立的 Shared；保留 Hub 中心同步拓扑、单写入节点、本地目录访问和 Hub MCP。

空间标识在网络内唯一，迁移不改变标识。Hub 汇集所有空间，普通节点只同步自己的空间和 Shared；不增加其他空间订阅或跨节点写入代理。空间文件直接位于 data/spaces/<id>/，取消 agents/<id>/raw。目录映射作为空间或 Shared 的附属入口，不再建立独立 Workspace 对象。Shared 默认映射只读副本，Hub 可显式创建可写映射。Hub 的全部空间入口使用只读副本，避免本地正常操作误写接收目录。

MCP 不再绑定 Agent/Leader。每条静态密钥或 OAuth 连接明确记录指定空间读取、指定 Hub 空间读写、独立 Shared 权限。显式的全空间读取包含未来新增空间；不提供全空间写入通配。默认无权限。OAuth 一次性授权凭证在 Hub 本机预设范围，浏览器展示范围后用户批准连接；客户端不能扩大范围。单独撤销连接不删除知识。空间停用、归属变更使涉及该空间的既有显式授权失效，恢复归属也不自动恢复授权。

默认 kioku skill 保留为操作指南。kioku-curate 是可选实践，用户可自行替换；程序不执行采集、回忆、提炼或 Agent 调度，也不解释提炼回执或预设知识分类。

这是破坏性接口变更，不长期保留 agent/source/workspace 命令别名。配置升级到版本 2，旧版本拒绝自动启动；显式迁移提供预览、停止服务检查、旧配置备份、目录原子移动与中断恢复。保留节点身份、空间归属、知识内容、已有目录入口及同步文件夹 ID；旧密钥和 OAuth 连接统一重新授权，旧签名邀请与迁移材料重新签发。所有节点升级完毕再恢复同步。现有节点部署不属于本次仓库交付。

本决策替代 ADR 0003、0007、0008 中 Agent 身份、Leader 权限与授权绑定，调整 ADR 0004、0005 中来源登记和工作区模型及 ADR 0006 的映射选择。保留机器配对、单写入、Shared 防误写副本、OAuth PKCE/令牌轮换、最终一致及基础设施与执行分离的机制。
