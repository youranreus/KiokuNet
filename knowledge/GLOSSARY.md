# KiokuNet

KiokuNet 管理同一用户多台机器上的知识空间及其同步与访问。使用知识的程序、助手身份、会话和运行器不属于产品模型。

## Language

**记忆网络 Network**：
同一位用户拥有的节点与知识空间的共享范围。
_Avoid_：单个项目目录、某个助手的内置记忆。

**节点 Node**：
接入网络的机器单位，例如 VPS 或用户电脑。一个节点可以拥有零个或多个知识空间。
_Avoid_：Agent、会话、知识空间。

**Hub**：
网络的中心节点角色，汇集各空间的同步副本并持有 Shared。
_Avoid_：Leader、知识整理者。

**知识空间 Knowledge Space**：
具有网络内唯一标识和单一写入节点的知识目录。空间迁移后保留标识；内容组织及使用方式由用户决定。
_Avoid_：Agent 身份、来源身份、每次会话自动创建的目录。

**写入节点 Owning Node**：
在某一时刻拥有一个空间写入归属的节点。其他节点上的同步副本不具有该空间的写入权。
_Avoid_：唯一写入进程、使用该空间的客户端所在机器。

**公共知识 Shared**：
由 Hub 持有、向其他节点分发的网络公共知识区，暂时独立于普通空间。其内容与维护方法由用户决定。
_Avoid_：Leader 身份、自动提炼产物、全部内容已被用户确认的事实集。

**目录映射 Directory Mapping**：
让本地程序通过指定路径访问空间或 Shared 的入口配置。一个空间可以有多个入口，移除入口不删除知识。
_Avoid_：独立 Workspace、知识归属、自动阅读触发器。

**只读副本 Read-only Copy**：
供本地程序读取并防误写的派生知识副本，反映最近一次成功刷新时的内容。
_Avoid_：知识本体、备份、针对本机所有者的安全隔离。

**连接授权 Connection Grant**：
用户为一条远程连接明确授予的空间与 Shared 访问范围。授权独立于任何助手身份，撤销连接不改变知识归属或删除知识。
_Avoid_：Agent 登记、节点入网、客户端注册即获得知识访问权。

**空间权限 Space Permissions**：
连接对指定空间的读取或读写范围；可显式选择读取所有当前及未来空间。写入权限仍受单写入节点约束，Shared 单独授权。
_Avoid_：成员或 Leader 角色、按工具名称推断权限。

**接入邀请 Invitation**：
Hub 发起的节点加入材料，用于识别目标网络并完成机器配对。空间迁移的专用加入材料还可以携带经确认的空间转移信息。
_Avoid_：远程连接授权、云存储凭据。

**接入回执 Enrollment Receipt**：
节点响应邀请产生的设备登记材料，供 Hub 完成双向配对。
_Avoid_：知识整理回执。
