# KiokuNet

KiokuNet 为同一位用户的多个 Agent 提供保留来源信息的个人记忆网络。以下术语区分知识归属、机器位置与知识维护责任。

## Language

**记忆网络 Memory Network**：
同一位用户拥有、由多个节点和 Agent 实例共同使用的知识共享范围。
_Avoid_：用单个 Agent 的内置记忆指代整个记忆网络。

**节点 Node**：
记忆网络中的机器接入单位，一台机器可以承载多个 Agent 实例。
_Avoid_：将节点与 Agent 实例混称为 Agent。

**运行器 Runtime**：
承载 Agent 执行的工具或系统，例如 Codex、Hermes、Pi。运行器类型不代表某个长期 Agent 的身份。
_Avoid_：用工具名称替代 Agent 实例身份。

**Agent 实例 Agent Instance**：
具有稳定身份和长期知识归属的助手。它可以跨会话工作，也可以在迁移后继续保留同一身份。
_Avoid_：把每次聊天、每个项目或同类运行器的全部使用者自动视为一个独立 Agent。

**Agent 身份 Agent Identity**：
用于区分长期 Agent 实例的稳定标识，知识归属以来源目录为单位。Agent 身份不代表节点身份或机器入网的信任凭据。
_Avoid_：机器地址、运行器名称、会话编号。

**会话 Session**：
Agent 实例的一段具体交互或执行过程，是知识来源的补充信息。
_Avoid_：长期身份。

**Hub**：
汇集各 Agent 原始知识并分发公共知识的中心节点角色。
_Avoid_：Leader、公共知识本身。

**Leader**：
能够读取全部接入 Raw，并负责提炼、纠错和维护公共知识的 Agent 角色。其运行位置可以与 Hub 不同，公共知识的写入归属仍在 Hub。
_Avoid_：Hub 机器、任务调度平台。

**原始知识 Raw Knowledge**：
由一个来源目录持有、可自由维护的当前知识文件，是后续提炼的依据。
_Avoid_：只允许追加的日志、对 Leader 不可见的私密目录、可恢复任意历史的档案。

**公共知识 Shared Knowledge**：
由 Leader 维护、供记忆网络中的 Agent 共同使用的知识。它保留来源，并表达当前结论及仍存在的不确定性。
_Avoid_：全部 Raw 的简单合并、全部内容都已被用户确认的事实集。

**知识提炼 Curation**：
将原始知识整理为可复用公共知识的过程，包括识别重复、处理冲突、保留来源和更新结论。
_Avoid_：删除原文、自动把助手建议升级为用户决策。

**身份绑定 Identity Binding**：
将调用与长期 Agent 实例及其角色对应的关系。远程访问通过凭据绑定身份；工作区目录中的普通文件操作无需逐次绑定。
_Avoid_：设备认证、全机共享的当前 Agent。

**接入邀请 Invitation**：
由 Hub 发起、面向新节点的加入材料，供机器识别目标网络和接入意图，不绑定某个 Agent 来源。
_Avoid_：设备私钥、云存储凭据。

**接入回执 Enrollment Receipt**：
新节点响应邀请产生的设备登记材料，供 Hub 完成双向配对和共享关系配置。
_Avoid_：知识整理回执。

**来源目录 Source Directory**：
具有明确知识归属和单一写入节点的 Raw 目录。多个工作区入口可以指向同一来源。
_Avoid_：运行器类型、一次会话、工作区入口本身。

**来源登记 Source Registration**：
在记忆网络中确认来源及其写入节点归属的记录关系，独立于机器配对和工作区接入。
_Avoid_：再次邀请机器、创建工作区链接、允许多节点共同写入。

**工作区入口 Workspace Entry**：
让 Agent 在工作区访问来源目录或公共知识的文件路径。入口位置与实际数据存储位置可以不同。
_Avoid_：知识副本、自动阅读触发器、权限机制本身。

**只读副本 Read-only Shared Copy**：
公共知识在本机供普通 Agent 读取并防误写的派生副本，表达最近一次成功刷新时的内容。
_Avoid_：独立知识来源、历史备份、主动绕过防护、公共知识本体。
